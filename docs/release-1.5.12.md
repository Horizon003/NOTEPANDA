# NotePanda 1.5.12 — Overall Rank & New Brand

This release applies the NotePanda identity across the native Flutter app and
moves the study league to one overall board. Learners can join with a display
name and choose public or private visibility; professional-year verification is
not required for ranking.

- New NotePanda panda launcher, splash and in-app branding.
- Frosted, rounded ranking/privacy prompt with compact controls.
- Firebase-native overall ranking ledger and public projection rules.
- Existing package ID `com.hyzen.pharmd` and production signing certificate
  remain unchanged.

The signed universal APK, checksum, emulator install/update smoke logs and
native test artifact are attached by the release workflow after validation.
